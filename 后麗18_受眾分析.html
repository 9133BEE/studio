2
投資理財組 CPL NT$175.70 最低但已停 → 換素材重開
27訊息＋1潛客，CPL NT$175.70 是全案最低，但已停止。建議搭配「大樓價」對比素材重開，強調「大樓的錢買后里4房透天，NT$1,488萬固定總價，18戶限量」，投資置產族對稀缺性＋固定總價訴求最敏感。
3
科技業家庭（21訊息 CPL $154 素材）配合新素材重啟
「0302_大樓價」搭配科技業受眾時 CPL $154 全案最低，但整組已停。建議重開「28-50/后里中科/科技業家庭」搭配新素材「后科鄰距離」，強調「中科下班到后里15分鐘，4房透天換公寓同樣預算」。
4
「大樓價」對比素材是全案王牌，應持續作為主力
0302_大樓價（影片＋單圖）合計貢獻約 95+ 訊息，CPL 最低 $154，是全案效率最高素材系列。「大樓的錢買得到透天嗎？后里可以」這個對比訴求對換屋族群說服力強。新素材應延伸此邏輯，不要偏離太遠。
5
「后科鄰距離」最新素材 CPL $127 最低，需更多量驗證
20260601_后科鄰距離是最新推出素材，最低版本 CPL NT$127，但目前只有 2 則訊息量太少。建議擴大測試：搭配傳產/自營組和科技業組，給予足夠預算（NT$200/日×7天），驗證是否能穩定在 CPL $150 以下。

建議新測試受眾方向 · 更新 2026-06-04
28–50 / 台中市+豐原 / 寵物大型犬飼主換屋 ↗
大型犬飼主在公寓受限極大（電梯、管委會禁養），透天前院是完美解法。寵物食品+動物醫院+大型犬標籤，切角「前院讓狗狗自由跑，4房透天全家開心住」，完全未嘗試的生活型態族群，台中養狗家庭數量可觀
30–55 / 台中豐原后里 / 電動車+EV充電族群 ↗
建案強調EV充電設施是少數建案亮點，但從未針對電動車主做廣告。Tesla+電動車+充電樁標籤，切角「后麗18直接裝充電樁，回家充電不靠外面」，EV車主換屋首要條件是充電方便，是精準行為受眾，完全未測
30–55 / 后里豐原 / 重機+越野族+大車庫需求 ↗
透天1樓停車+前院是重機族、多車族的夢想格局，公寓根本無法滿足。重型機車+越野車+改裝車標籤，切角「1樓停車，前院放重機，4房不擠」，休閒用車族有強烈透天需求但廣告中完全未觸及
28–48 / 台中市 / 居家辦公+接案族群（WFH需獨立空間）↗
4房格局：主臥、兒房、客房，還能多一間書房/工作室。Freelancer+遠端工作+數位創業+設計師標籤，切角「一間房工作，三間房生活，后里透天讓你不再擠」，WFH族對空間需求強，完全未測試
35–60 / 嘉義+彰化+雲林 / 外縣市第一戶台中置產 ↗
嘉義/雲林/彰化人移往台中的趨勢明顯，后里在國道一號旁是進入台中的第一站。設定居住地為南部縣市、工作/互動在台中，切角「嘉義人在台中買第一間，后里透天最划算」，地理擴展全新方向
30–55 / 台中豐原 / 菜園+自耕農興趣族（前院種菜）↗
后里農業環境濃厚，透天前院天然適合種菜/花圃。有機農業+園藝+植物標籤，切角「前院種菜，後院放孩子，台中后里新透天」，崇尚田園生活但不捨城市便利的族群，是透天產品的天然受眾，完全未開過
28–45 / 台中市 / 591主動搜尋行為再行銷 ↗
正在 591/樂屋/信義搜尋透天別墅的人是最精準熱需求受眾。使用「訪問過競品房產網站」行為受眾，立刻搭配「后麗18限18戶、現在入住」強效CTA素材，行為型受眾CPL歷史最低，但从未建立，應立即設定
35–60 / 台中+豐原 / 戶外露營+登山+溫泉旅遊族 ↗
后里鄰近大雪山、有溫泉、麗寶可戶外活動，戶外族群對「回家像度假」共鳴強。露營+登山+溫泉+戶外活動標籤，切角「台中后里是你的戶外基地，透天4房週末出發最方便」，生活型態受眾完全未測試
